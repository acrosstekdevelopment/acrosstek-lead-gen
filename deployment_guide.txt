1. PRODUCTION ARCHITECTURE
===============================================================================

Frontend and backend do NOT both run on Node.js in production.

  ┌──────────────────────────────────────────────────────────────┐
  │  BROWSER (scale.acrosstek.in)                                │
  │     ↓                                                        │
  │  NGINX (port 80/443)                                         │
  │     ├── /             → serves static files from client/dist │
  │     ├── /api/*        → proxy to Node.js on port 5002        │
  │     └── /socket.io/*  → proxy to Node.js on port 5002        │
  │                                                              │
  │  NODE.JS (PM2, port 5002)                                    │
  │     └── server/server.js (Express + Socket.IO)               │
  │                                                              │
  │  MONGODB (port 27017)                                        │
  │     └── leadgen database                                     │
  └──────────────────────────────────────────────────────────────┘

  - Frontend: Pre-built static files (npm run build → client/dist/).
    Nginx serves them directly. No Vite or Node needed for frontend.
  - Backend: Node.js Express app, managed by PM2 for auto-restart.
  - Both on the SAME VPS, same machine. Nginx routes traffic.

2. GOOGLE SHEETS — FRESH START
===============================================================================

Do NOT copy .sheet_ids.json or .google_tokens.json to the VPS.

  - MongoDB on VPS will be fresh → no existing data.
  - On first pipeline run, ensureSheets() auto-creates 4 new Google Sheets.
  - Old sheets on your laptop stay untouched.
  - You need to re-authorize Google Sheets on the VPS (Section 7).

5. VPS SERVER SETUP (Hostinger)
===============================================================================

SSH into your VPS:
  ssh root@YOUR_VPS_IP

───── 5.1: Update system ─────
  apt update && apt upgrade -y

───── 5.2: Install Node.js 20+ ─────
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
  apt install -y nodejs
  node -v
  npm -v

───── 5.3: Install Python 3 + pip ─────
  apt install -y python3 python3-pip python3-venv
  pip3 install requests beautifulsoup4 lxml

───── 5.4: Install MongoDB ─────
  # For Ubuntu 22.04:
  curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | \
    gpg --dearmor -o /usr/share/keyrings/mongodb-server-7.0.gpg
  echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] \
    https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | \
    tee /etc/apt/sources.list.d/mongodb-org-7.0.list
  apt update
  apt install -y mongodb-org
  systemctl start mongod
  systemctl enable mongod
  mongosh --eval "db.runCommand({ping:1})"

───── 5.5: Install PM2 ─────
  npm install -g pm2

───── 5.6: Install Nginx ─────
  apt install -y nginx
  systemctl enable nginx

───── 5.7: Install Certbot (SSL) ─────
  apt install -y certbot python3-certbot-nginx

───── 5.8: Point domain to VPS ─────
  In your DNS settings (Hostinger or domain registrar):
    A record: scale.acrosstek.in → YOUR_VPS_IP
  Wait for DNS propagation (can take 5-30 minutes).

6. DEPLOY THE APPLICATION
===============================================================================

───── 6.1: Clone repo ─────
  cd /var/www
  git clone https://github.com/CeasaKK/n8n-backend-frontend.git leadgen
  cd leadgen

───── 6.2: Install dependencies ─────
  cd server && npm install && cd ..
  cd client && npm install && npm run build && cd ..
  pip3 install requests beautifulsoup4 lxml

───── 6.3: Create production .env ─────
  nano .env

  ┌──────────────────────────────────────────────────────────────────────┐
  │ MONGO_URI=mongodb://127.0.0.1:27017/leadgen                         │
  │ PORT=5002                                                           │
  │ SEARCH_ENGINE_ID=your_search_engine_id                              │
  │ SEARCH_ENGINE_API_KEY=your_search_engine_api_key                    │
  │ APIFY_API_KEY=your_apify_api_key                                   │
  │ SNOV_CLIENT_ID=your_snov_client_id                                 │
  │ SNOV_CLIENT_SECRET=your_snov_client_secret                         │
  │ GOOGLE_SHEETS_CLIENT_ID=your_google_sheets_client_id               │
  │ GOOGLE_SHEETS_CLIENT_SECRET=your_google_sheets_client_secret       │
  │ GOOGLE_SHEETS_REDIRECT_URI=https://scale.acrosstek.in/api/sheets/auth/callback │
  │ EXT_APIKEY_LINKEDIN_JOBS=your_linkedin_jobs_key                    │
  │ EXT_APIKEY_STACKOVERFLOW_JOBS=your_stackoverflow_jobs_key          │
  │ EXT_APIKEY_MONSTER=your_monster_key                                │
  │ EXT_APIKEY_YC_JOBS=your_yc_jobs_key                                │
  │ EXT_APIKEY_WELLFOUND_JOBS=your_wellfound_jobs_key                  │
  └──────────────────────────────────────────────────────────────────────┘

───── 6.4: Configure Nginx ─────
  nano /etc/nginx/sites-available/leadgen

  ┌──────────────────────────────────────────────────────────────┐
  │ server {                                                     │
  │     listen 80;                                               │
  │     server_name scale.acrosstek.in;                          │
  │                                                              │
  │     # Serve React frontend (static build)                    │
  │     root /var/www/leadgen/client/dist;                       │
  │     index index.html;                                        │
  │                                                              │
  │     # API proxy to Node.js backend                           │
  │     location /api/ {                                         │
  │         proxy_pass http://127.0.0.1:5002;                    │
  │         proxy_http_version 1.1;                              │
  │         proxy_set_header Upgrade $http_upgrade;              │
  │         proxy_set_header Connection 'upgrade';               │
  │         proxy_set_header Host $host;                         │
  │         proxy_cache_bypass $http_upgrade;                    │
  │         proxy_read_timeout 300s;                             │
  │     }                                                        │
  │                                                              │
  │     # Socket.IO proxy                                        │
  │     location /socket.io/ {                                   │
  │         proxy_pass http://127.0.0.1:5002;                    │
  │         proxy_http_version 1.1;                              │
  │         proxy_set_header Upgrade $http_upgrade;              │
  │         proxy_set_header Connection 'upgrade';               │
  │         proxy_set_header Host $host;                         │
  │     }                                                        │
  │                                                              │
  │     # React SPA fallback (serves index.html for all routes)  │
  │     location / {                                             │
  │         try_files $uri $uri/ /index.html;                    │
  │     }                                                        │
  │ }                                                            │
  └──────────────────────────────────────────────────────────────┘

  Enable the site:
    ln -s /etc/nginx/sites-available/leadgen /etc/nginx/sites-enabled/
    rm /etc/nginx/sites-enabled/default
    nginx -t
    systemctl restart nginx

───── 6.5: Get SSL certificate ─────
  certbot --nginx -d scale.acrosstek.in
  # Choose: redirect HTTP to HTTPS

───── 6.6: Start backend with PM2 ─────
  cd /var/www/leadgen/server
  pm2 start server.js --name "leadgen-api"
  pm2 save
  pm2 startup    # Run the command it prints to enable auto-start on reboot

───── 6.7: Verify ─────
  curl http://localhost:5002/api/health
  # Should return: {"status":"ok","timestamp":"..."}

  Visit https://scale.acrosstek.in in browser — should see the frontend.

7. GOOGLE SHEETS AUTH ON PRODUCTION
===============================================================================

  1. Go to: https://console.cloud.google.com
     → APIs & Services → Credentials → Your OAuth 2.0 Client ID
     → Add this to "Authorized redirect URIs":
       https://scale.acrosstek.in/api/sheets/auth/callback

  2. Visit: https://scale.acrosstek.in/api/sheets/auth
     → Sign in with your Google account → Authorize

  3. Tokens are saved to .google_tokens.json on the VPS.

  4. Run a pipeline — 4 new Google Sheets will be created automatically.

10. TROUBLESHOOTING
===============================================================================

  pm2 logs leadgen-api            # View backend logs
  pm2 restart leadgen-api         # Restart backend
  systemctl status nginx          # Check Nginx
  systemctl restart nginx         # Restart Nginx
  mongosh                         # Check MongoDB
  certbot renew --dry-run         # Test SSL renewal

  If scrapers fail:
    python3 /var/www/leadgen/jobs_scraper-main/job_scrapers/scrape_arcdev.py

  If Google Sheets auth fails:
    rm /var/www/leadgen/.google_tokens.json
    Visit: https://scale.acrosstek.in/api/sheets/auth

  If frontend shows blank page:
    cd /var/www/leadgen/client && npm run build
    systemctl restart nginx
